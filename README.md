## ✨ Overview

This is my personal developer portfolio — a fully custom, animation-heavy single-page site built from scratch with vanilla **HTML, CSS, and JavaScript** (no frameworks). It's designed to feel less like a static resume and more like a small interactive experience: a working terminal, an orbiting skills visualization, draggable project & certificate carousels, and a live map pin dropped right on my location.

## 🚀 Features

- 🖥️ **Interactive Terminal** — type `help` in the hero terminal to explore commands, just like a real shell
- 🪐 **Orbiting Skills Visualization** — animated, physics-driven skill icons
- 🎞️ **Drag-to-scroll Project & Certificate Carousels** — smooth, touch/mouse-friendly showcases
- 🗺️ **Live Leaflet Map** — pinpoints my location with zoom controls
- 📬 **Working Contact Form** — powered by EmailJS, sends messages directly to my inbox
- 🎨 **Custom Cursor + Grain Overlay + Scroll Reveals** — small polish details throughout
- 📱 **Fully Responsive** — dedicated mobile nav and layout

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (custom properties, animations) |
| Fonts | Space Mono, Syne (Google Fonts) |
| Interactivity | Vanilla JavaScript (Canvas, DOM, event-driven) |
| Maps | Leaflet.js |
| Contact | EmailJS |
| Hosting | Vercel |

## 🧑‍💻 Getting Started

```bash
git clone https://github.com/Sahilmore469/PortFolio-sahil2.git
cd PortFolio-sahil2
```

Just open `index.html` in your browser — no build step required. For live-reload during development, use any static server, e.g.:

```bash
npx serve .
```

> To enable the contact form locally, add your own EmailJS public key, service ID, and template ID inside `index.html`.
